# FitFuel 🥗💪

**FitFuel** is a full-stack nutrition and fitness platform — available as a web app and a native mobile app.

Track your macros, log workouts, browse AI-generated meal ideas, find nearby grocery deals, and manage your food budget across Canadian supermarkets.

---

## Packages

| Folder | Description | Stack |
|--------|-------------|-------|
| [`/web`](./web) | Next.js web application | Next.js 14, TypeScript, Tailwind CSS, Groq/Llama 3, Leaflet |
| [`/mobile`](./mobile) | Expo React Native mobile app | Expo SDK 54, React Native 0.81, Expo Router |

---

## Features

- **Dashboard** — Daily calorie ring, protein/carb/fat bars, step counter, workout streak
- **Meal Tracker** — Log meals and workouts with macro breakdown
- **Meal Browser** — Browse 13 curated meals with photos, recipes, and macros (TheMealDB)
- **AI Chef** — Enter your ingredients, get full meal plans generated by Llama 3 (Groq)
- **Grocery Deals** — Find nearby grocery stores on an interactive map + weekly flyer deals
- **Budget Tracker** — Compare ingredient prices across 8 major Canadian supermarkets

## Getting Started

### Web App

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> Requires a `.env.local` with `GROQ_API_KEY=your_key`.

### Mobile App

```bash
cd mobile
npm install
npx expo start
```

Scan the QR code with [Expo Go](https://expo.dev/go) on your phone.

> Requires a `.env.local` with `EXPO_PUBLIC_API_URL=http://YOUR_LOCAL_IP:3000`.  
> Your phone and PC must be on the same Wi-Fi network.

## Tech Stack

**Web**
- [Next.js 14](https://nextjs.org/) + TypeScript + Tailwind CSS v4
- [Groq SDK](https://groq.com/) / Llama 3 for AI meal generation
- [Leaflet](https://leafletjs.com/) / OpenStreetMap for interactive maps
- [TheMealDB](https://themealdb.com/) for meal data
- Nominatim + Overpass API for store search

**Mobile**
- [Expo SDK 54](https://expo.dev/) + React Native 0.81
- [Expo Router](https://expo.github.io/router/) — file-based tab navigation
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/) for local persistence
- Expo Location, Haptics, Linear Gradient
